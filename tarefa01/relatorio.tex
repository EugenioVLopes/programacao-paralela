\section{Enunciado}

Implementar em C um programa para calcular a aproximação de $\pi$ por meio de uma série matemática, variando o número de iterações e mensurando o tempo de execução. O objetivo envolve comparar os valores obtidos com a constante de referência $\pi$, analisar a evolução da acurácia com o aumento do processamento e avaliar como esse comportamento se manifesta em aplicações reais de alto desempenho, tais como simulações físicas e inteligência artificial.

% 2. Fundamentação Teórica
\section{Fundamentação Teórica}

\subsection{Série de Leibniz}
A série de Leibniz para $\pi$ é dada por:
\[
\pi = 4 \sum_{k=0}^{\infty} \frac{(-1)^k}{2k+1} = 4 \left(1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \cdots\right)
\]


\subsection{Algoritmo}
\begin{enumerate}
    \item Inicializar \texttt{pi} com 0.0;
    \item Para cada iteração $k$ de 0 até $N-1$:
    \begin{itemize}
        \item Calcular o termo: $\frac{1}{2k+1}$;
        \item Aplicar sinal alternado: positivo para $k$ par, negativo para $k$ ímpar;
        \item Acumular o termo no somatório;
    \end{itemize}
    \item Multiplicar o resultado por 4;
    \item Calcular o erro absoluto: $|\pi_{\text{aprox}} - \pi_{\text{real}}|$.
\end{enumerate}

\section{Experimento}

\subsection{Código-Fonte}
O programa recebe o número de iterações como argumento de linha de comando e calcula a aproximação de $\pi$ pela série de Leibniz.

\begin{lstlisting}[caption={Código-fonte em C para aproximação de $\pi$}, label={lst:codigo}]
#include <stdio.h>
#include <stdlib.h>
#include <math.h>

int main(int argc, char *argv[]) {
    if (argc != 2) {
        printf("Uso: %s <numero_de_iteracoes>\n", argv[0]);
        return 1;
    }

    long long N = atoll(argv[1]);
    double pi = 0.0;

    for (long long k = 0; k < N; k++) {
        double termo = 1.0 / (2.0 * k + 1.0);
        pi += (k % 2 == 0) ? termo : -termo;
    }
    pi *= 4.0;

    double erro = fabs(pi - M_PI);

    printf("Iteracoes: %lld\n", N);
    printf("Pi:        %.15f\n", pi);
    printf("Erro:      %.2e\n", erro);

    return 0;
}
\end{lstlisting}

O tempo de execução é medido externamente por meio do utilitário \texttt{time} do shell Linux, variando-se o argumento de iterações a cada execução:
\begin{lstlisting}[caption={Exemplo de execução com medição de tempo}, label={lst:execucao}]

\end{lstlisting}

\subsection{Observações Principais}
\begin{itemize}
    \item O erro absoluto decresce em uma ordem de magnitude a cada aumento de 10 vezes no número de iterações;
    \item O tempo de execução cresce linearmente em relação ao número de iterações processadas;
    \item Atinge-se precisão da ordem de $10^{-9}$ com $10^9$ iterações.
\end{itemize}

% 5. Discussão
\section{Discussão}

A relação de compromisso (\textit{trade-off}) entre precisão numérica e custo computacional motiva o emprego de técnicas de paralelização e de séries com taxas de convergência superiores. Métodos alternativos à série de Leibniz, tais como a fórmula de Machin ou os algoritmos baseados em Ramanujan e Chudnovsky, convergem com maior rapidez, exigindo menor quantidade de iterações para atingir a mesma tolerância de erro.

De modo análogo, a distribuição das etapas de cálculo entre múltiplos núcleos de processamento (CPUs) ou aceleradores gráficos (GPUs) viabiliza a redução substancial do tempo de execução sem prejuízo da exatidão requerida. Trata-se de uma abordagem indispensável em simulações físicas de larga escala e no treinamento de modelos modernos de inteligência artificial, cenários em que o processamento intensivo em paralelo viabiliza o tratamento de grandes volumes de dados em tempo hábil.

\section{Conclusão}
O experimento demonstra, em escala controlada, um princípio fundamental da computação científica: a obtenção de maior precisão numérica acarreta custo computacional progressivo, o qual cresce de forma desproporcional ao ganho incremental de exatidão na série de Leibniz. Esse princípio orienta decisões de projeto em sistemas de alto desempenho, nos quais a escolha criteriosa de algoritmos eficientes, a aplicação de técnicas de paralelismo e a definição de tolerâncias de erro determinam a viabilidade prática das soluções computacionais.
