Referencia rapida sobre critical, locks e tasks

Consulta rapida para a tarefa 09.

1. Tabela de sincronizacao

RecursoSintaxeEfeito
critical anonimo#pragma omp criticallock global unico
critical nomeado#pragma omp critical(lista0)um lock por nome
lock initomp_init_lock(&locks[i])cria antes do paralelo
lock usoomp_set_lock(&locks[q])espera e entra
lock liberaomp_unset_lock(&locks[q])libera a fila
lock fimomp_destroy_lock(&locks[i])desfaz depois do uso
Regra de ouro
Mesmo nome espera junto. Nome diferente anda junto. Nome nao indexa por variavel.

2. Padroes da tarefa

V1 com dois nomes isola as listas.

if (qual == 0) { #pragma omp critical(lista0)
  inserir(&head0, v); } else { #pragma omp critical(lista1)
  inserir(&head1, v); }

V2 com vetor de locks escala para N listas.

omp_set_lock(&locks[qual]);
inserir(&heads[qual], v);
omp_unset_lock(&locks[qual]);

Tasks com seed privada por i.

#pragma omp parallel shared(heads,locks,N) default(none)
{ #pragma omp single
  { for (i=0;i<N;i++) { #pragma omp task firstprivate(i)
    { seed = 999u + i*40503u; qual = rand_r(&seed) % nlistas; } } } }

3. Resumo executivo

Medicao com agora sobre clock_gettime com CLOCK_MONOTONIC. Compila com gcc menos O2 menos fopenmp menos Wall menos lm. Cada ponto vale a mediana de 3 repeticoes.

Sao 2 programas. V1 usa critical com 2 listas. V2 usa locks com N listas via argv de 2. Com N igual a 50000 v1 deu 24998 contra 25002 OK e v2 deu total OK.

Constantes: 2654435761u na v1 e 40503u na v2 para espacar seeds. Flags: menos std igual a c11 menos O2 menos Wall menos fopenmp.
