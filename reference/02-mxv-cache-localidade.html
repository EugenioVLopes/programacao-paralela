Referência rápida 02: MxV — Cache e Localidade em C

Guia de consulta rápida para a Tarefa 02 (Multiplicação Matriz-Vetor)

1. Funções de alocação dinâmica

Função Assinatura Inicializa? Uso típico
malloc void *malloc(size_t n) Não (lixo de memória) Aloca bloco; conteúdo indiferente
calloc void *calloc(size_t n, size_t sz) Sim (zeros) Vetor acumulador y[]
realloc void *realloc(void *p, size_t n) Preserva dados anteriores Redimensionamento de buffer
free void free(void *p) — Libera bloco alocado 
/* Matriz N×N armazenada como vetor 1-D (row-major) */
double *A = malloc((size_t)N * N * sizeof(double));
double *x = malloc(N * sizeof(double));
double *y = calloc(N, sizeof(double));  /* inicializado com zero */

/* Verificação obrigatória em código de produção */
if (!A || !x || !y) { perror("malloc"); return 1; }

free(A); free(x); free(y);
Por que (size_t)N * N?

Se N é int (32 bits) e $N = 50\,000$, então N * N = 2.5 × 10⁹ estoura um int com sinal. O cast (size_t) garante aritmética de 64 bits antes da multiplicação.

2. Aritmética de ponteiros e indexação da matriz

Expressão Endereço de memória Padrão de acesso
A[i*N + j] base + (i*N + j)*8 Row-major — sequencial em $j$
A[j*N + i] base + (j*N + i)*8 Column-major — salto de N em $i$
*(A + i*N + j) idêntico a A[i*N+j] Acesso por ponteiro explícito
A + i*N Início da linha $i$ Ponteiro para a i-ésima linha
$$A[i][j] \;\equiv\; A[i \cdot N + j] \quad (\text{row-major, C})$$ 
/* Row-major: laço interno em j → acesso sequencial (cache-friendly) */
for (int i = 0; i < N; i++) {
    double s = 0.0;
    for (int j = 0; j < N; j++)
        s += A[i * N + j] * x[j];
    y[i] = s;
}

/* Column-major: laço interno em i → stride = N×8 bytes (cache-unfriendly) */
for (int j = 0; j < N; j++) {
    for (int i = 0; i < N; i++)
        y[i] += A[i * N + j] * x[j];
}

3. Medição de tempo com clock()

Símbolo / tipo Descrição Valor típico (Linux)
clock_t Tipo inteiro para ticks de CPU long int
clock() Retorna ticks de CPU consumidos Definido em <time.h>
CLOCKS_PER_SEC Ticks por segundo 1 000 000 (10⁶)
(fim - inicio) / CLOCKS_PER_SEC Tempo em segundos Precisão de ~1 µs 
#include <time.h>

clock_t inicio = clock();

/* ... trecho a medir ... */

clock_t fim = clock();
double tempo = (double)(fim - inicio) / CLOCKS_PER_SEC;
printf("tempo = %.6f s\n", tempo);

4. Flags de compilação relevantes

Flag Efeito Observação
-O0 Sem otimização (linha de base) Facilita depuração com GDB
-O2 Otimizações seguras (aliasing) Inline, loop unroll parcial
-O3 Otimizações agressivas Vetorização SIMD automática
-march=native Usa ISA do hardware local AVX2/AVX-512 se disponível
-Wall Ativa avisos comuns Recomendado sempre
-lm Liga a libm (funções matem.) Necessário para sqrt, pow 
# Compilar e medir diferença de desempenho:
gcc -O2 -Wall -o row_major   row_major.c
gcc -O2 -Wall -o collum_major collum_major.c

./row_major   2000
./collum_major 2000

# Com perf para contar cache misses (Linux):
perf stat -e cache-misses,cache-references ./row_major   2000
perf stat -e cache-misses,cache-references ./collum_major 2000

5. Resumo executivo de fórmulas

Regras práticas — MxV e cache
  • Linha de cache = 64 bytes = 8 doubles.
  • Row-major: 1 miss a cada 8 acessos à matriz $A$ ($\approx 12{,}5\%$).
  • Column-major: ~1 miss por acesso ($\approx 100\%$).
  • Stride column-major: $N \times 8$ bytes ($= 16\,000$ B para $N=2000$).
  • Intensidade aritmética MxV: $I = 0{,}25$ FLOP/byte.
  • Teto de desempenho (Roofline): $I \times B_{\text{mem}}$ GFLOP/s.
  • Cast (size_t) antes de multiplicar dimensões grandes.
  • Use calloc para vetores que devem começar em zero.
