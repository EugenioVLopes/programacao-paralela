Cheatsheet: OpenMP e Variáveis de Ambiente

1. Controle de threads no terminal

A variável de ambiente OMP_NUM_THREADS define o total de threads da execução:

# Compilação padrão ativando OpenMP
$ gcc -std=c11 -Wall -Wextra -fopenmp programa.c -o programa -lm

# Define para 4 threads e executa
$ export OMP_NUM_THREADS=4
$ ./programa

# Executa definindo a variável inline
$ OMP_NUM_THREADS=2 ./programa

2. Divisão de laços com OpenMP

#pragma omp parallel for
for (long i = 0; i < total_elementos; ++i) {
    C[i] = A[i] + B[i];
}

Funções da biblioteca OpenMP

#include <omp.h>

int total_threads = omp_get_max_threads(); // Retorna o limite de threads
int id_thread = omp_get_thread_num();     // Retorna o ID da thread atual (0 a N-1)
