Sintaxe OpenMP

Diretivas pragma e controle de threads no terminal

Controle de execução no Terminal (Bash)

A variável de ambiente OMP_NUM_THREADS define globalmente a quantidade de threads que o OpenMP irá utilizar durante a execução, sem precisar alterar o código fonte.

# Compilação padrão ativando OpenMP
$ gcc -O3 -fopenmp meuprog.c -o meuprog -lm

# Define para 4 threads e executa
$ export OMP_NUM_THREADS=4
$ ./meuprog

# Executa definindo a variável para um único comando (inline)
$ OMP_NUM_THREADS=2 ./meuprog

Diretivas Pragma em C

As diretivas do compilador instruem como o código sequencial deve ser dividido.

Divisão de Laço (Parallel For)

#pragma omp parallel for
for (int i = 0; i < N; i++) {
    // O espaço de iteração [0, N) é dividido
    // automaticamente entre as threads ativas.
    vetor[i] = vetor[i] * 2.0;
}

Funções da biblioteca OpenMP

#include <omp.h>

int n_threads = omp_get_max_threads(); // Lê o limite de threads
int thread_id = omp_get_thread_num();  // ID da thread atual (0 a N-1)
