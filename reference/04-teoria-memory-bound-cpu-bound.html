Teoria: Aplicações Limitadas por Memória e CPU

Gargalo de von Neumann, Intensidade Aritmética e Multithreading

1. Gargalo de von Neumann

A arquitetura de von Neumann separa a unidade de processamento da memória principal. O barramento de comunicação possui largura de banda finita.

O poder de cálculo da CPU aumentou mais rápido que a velocidade da memória DRAM. Essa diferença cria o gargalo de von Neumann. A CPU passa ciclos ociosa esperando a chegada dos dados.

2. Intensidade aritmética

A intensidade aritmética mede as operações de ponto flutuante realizadas por byte transferido:

$$\text{IA} = \frac{\text{FLOPs}}{\text{Bytes Transferidos}}$$

Aplicações com baixa intensidade aritmética esgotam a largura de banda da memória. Aplicações com alta intensidade aritmética ocupam as unidades de cálculo da CPU.

3. Limitado por memória vs Limitado por processamento

  • Limitado por memória: O tempo total depende da taxa de transferência da memória RAM. As unidades aritméticas passam tempo ociosas.
  • Limitado por CPU: O tempo total depende da velocidade de execução das instruções na CPU. O acesso à memória é infrequente.

4. Efeitos do multithreading em hardware

O multithreading produz resultados opostos dependendo do perfil da carga de trabalho:

  • Em aplicações limitadas por CPU: Mais threads ocupam unidades aritméticas livres e aumentam a taxa de processamento. O speedup escala com os núcleos.
  • Em aplicações limitadas por memória: Mais threads disputam o mesmo barramento saturado. O tempo de execução estagna ou piora devido à contenção.

1. Controle de threads no terminal

A variável de ambiente OMP_NUM_THREADS define o total de threads da execução:

# Compilação padrão ativando OpenMP
$ gcc -std=c11 -Wall -Wextra -fopenmp programa.c -o programa -lm

# Define para 4 threads e executa
$ export OMP_NUM_THREADS=4
$ ./programa

# Executa definindo a variável inline
$ OMP_NUM_THREADS=2 ./programa

2. Divisão de laços com OpenMP

#pragma omp parallel for
for (long i = 0; i < total_elementos; ++i) {
    C[i] = A[i] + B[i];
}

Funções da biblioteca OpenMP

#include <omp.h>

int total_threads = omp_get_max_threads(); // Retorna o limite de threads
int id_thread = omp_get_thread_num();     // Retorna o ID da thread atual (0 a N-1)
