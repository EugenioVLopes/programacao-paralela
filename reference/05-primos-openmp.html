Cheatsheet: Loop Parallelism & Reduction

1. Sintaxe Básica

#pragma omp parallel for
for (int i = 0; i < n; i++) {
    // Operações independentes sobre o dado 'i'
}
  • O laço for precisa ser estruturado de forma previsível (limites de iteração fixos e verificáveis no início, como i < n).
  • Variáveis declaradas dentro do escopo do laço for são privadas para cada thread por padrão.

2. Cláusula Reduction

int soma = 0;
#pragma omp parallel for reduction(+:soma)
for (int i = 0; i < n; i++) {
    soma += vetor[i];
}
Operador Elemento Neutro (Início Privado)
+0
*1
-0
& (AND lógico)1 (true)
| (OR lógico)0 (false)

3. Escalonamento Básico (Schedule)

A cláusula schedule(tipo, chunk) controla como as iterações são divididas.

  • schedule(static) (Padrão)
    Divide as iterações em blocos de tamanho igual em tempo de compilação. Perfeito para laços regulares. Baixíssimo custo.
  • schedule(dynamic, chunk_size)
    Threads requisitam blocos menores (chunk_size) sob demanda. Ótimo para carga desbalanceada, mas tem overhead em runtime.
