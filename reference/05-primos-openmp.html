Cheatsheet: Parallel For

1. Compilação e execução

# Compilação com OpenMP
$ gcc -std=c11 -Wall -Wextra -fopenmp tarefa05.c -o tarefa05 -lm

# Executa com o padrão de threads do sistema
$ ./tarefa05 5000000

# Define 4 threads e executa
$ export OMP_NUM_THREADS=4
$ ./tarefa05 5000000

# Executa definindo a variável inline
$ OMP_NUM_THREADS=2 ./tarefa05 5000000
  • O argumento é o limite superior $N$ para contagem de primos.
  • A saída mostra seq_time, par_time, seq_count e par_count.
  • Use ./execute.sh para rodar o experimento completo com todas as thread counts e gerar os gráficos.

2. Sintaxe básica

#pragma omp parallel for
for (long numero_atual = 0; numero_atual < limite_superior; numero_atual++) {
    // Operações independentes sobre o número atual
}
  • O laço precisa de limites fixos. O OpenMP calcula a divisão antes de executar.
  • Variáveis declaradas dentro do laço são privadas por padrão.

3. Escalonamento (schedule)

A cláusula schedule(tipo, tamanho_bloco) controla a divisão das iterações.

  • schedule(static) — Divide as iterações em blocos iguais no início. Custo mínimo. Ideal para carga uniforme.
  • schedule(dynamic, tamanho_bloco) — Cada thread requisita um bloco sob demanda. Mais overhead, mas equilibra carga desigual.

4. Race condition com variável compartilhada

long total_primos = 0;
#pragma omp parallel for
for (long numero_atual = 0; numero_atual < limite_superior; numero_atual++) {
    if (eh_primo(numero_atual)) total_primos++;  // Race condition: resultado incorreto
}

Múltiplas threads leem e escrevem total_primos ao mesmo tempo. O resultado fica corrompido.
