Fonte de todos os valores do passo n. Também contém os buffers dos envios.

next

Destino dos valores do passo n+1. O cálculo não modifica os dados enviados.

next[i] = current[i] + COEFFICIENT *
    (current[i - 1] - 2.0 * current[i] + current[i + 1]);

DCA3703 · Tarefa 158 / 15
MPI_TEST

Consultar não é garantir a conclusão

if (i % 1024 == 0) {
    if (!received_left)
        MPI_Test(&requests[0], &received_left, MPI_STATUS_IGNORE);
    if (!received_right)
        MPI_Test(&requests[1], &received_right, MPI_STATUS_IGNORE);
}

Flag verdadeira

O recebimento terminou. O buffer já contém os dados recebidos.

Flag falsa

A operação segue pendente. MPI_Wait garante sua conclusão antes de usar a borda.

Irecv prepara o buffer antes dos Isend; iniciar a operação não significa que o dado já chegou.

CONCLUSÃO

Sobrepor é uma possibilidade, não uma garantia

O que foi observado

Isend/Irecv + Wait teve a menor mediana. A troca não bloqueante não trouxe vantagem automática.

O que ficou em aberto

O custo dos testes e o progresso interno do MPI não foram isolados. Os avisos OpenFabrics caracterizam o ambiente.

Irecv prepara o destino; MPI_Test consulta; MPI_Wait garante a conclusão. Só há ganho quando o cálculo independente cobre a comunicação.
