## 2. Por que `long long` e não `int`?

`int` tem 32 bits e vai até cerca de 2 bilhões. Para N = 10 bilhões, estoura. `long long` tem 64 bits e suporta valores enormes sem problema. No Linux x86_64, `long` também é 64 bits, mas `long long` é garantido em qualquer plataforma.

## 3. Contador fora do laço

`dentro_circulo` precisa acumular o resultado de todas as iterações. Se estivesse dentro do laço, resetaria a cada iteração e o resultado seria sempre 1.

## 4. Transformando `rand()` para [-1, 1]

`rand()` retorna valores de 0 a RAND_MAX. Dividindo por RAND_MAX temos [0, 1]. Multiplicando por 2 temos [0, 2]. Subtraindo 1 temos [-1, 1]:

```c
double x = 2.0 * (double)rand() / (double)RAND_MAX - 1.0;
```

## 5. Condição de pertencimento ao círculo

Se x² + y² ≤ 1, o ponto está dentro do círculo unitário. É só comparar com 1.0 e incrementar o contador.

## 6. Divisão inteira

`4 * dentro_circulo / N` com dois `long long` faz divisão inteira, truncando o resultado. Um cast para `double` em um dos operandos corrige: `4.0 * dentro_circulo / N`.
